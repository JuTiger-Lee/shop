# PRD: 의류 쇼핑 페이지 (데모)

## 1. Context
학습/포트폴리오용 데모 의류 쇼핑 페이지. 탐색 → 상세 → 담기 → 장바구니 합계까지의 쇼핑 흐름을 보여준다. **결제·주문 기능은 없다.**

> **v1.1 변경**: 이후 결제 연동이 추가되었다. 아래 "비목표"와 "결정 사항"의 결제·주문 관련 항목은 8장(결제 연동)으로 대체된다.

## 2. 목표 / 비목표
**목표**
- 모바일 우선 반응형 SPA, 한국어 단일 언어
- 단일 브랜드 캐주얼 의류 스토어(성별 구분 없음): 상의 / 하의 / 아우터 / 액세서리

**비목표**
- 결제, 주문하기, 배송지 입력, 주문 내역, 로그인/회원가입, 백엔드/DB, 키워드 검색, 다크모드, 재고 수량 관리, 배송비/쿠폰

## 3. 결정 사항 (인터뷰 확정)
| 항목 | 결정 |
|------|------|
| 사용자 최종 행동 | 장바구니 + 위시리스트까지 |
| 데이터 | 정적 JS 목업 데이터(24개 상품) |
| 저장 | 브라우저 localStorage (장바구니, 위시리스트) |
| 스택 | React + Vite + Tailwind CSS, Vercel 배포 |
| 디자인 | 미니멀 무채색, 이미지 중심 |
| 가격 | 원화(₩, 천 단위 콤마), 약 1/4 상품에 할인가/할인율 |
| 접근성 | 키보드 조작, 이미지 alt, 빈 상태 화면 포함 |

## 4. 페이지 및 기능 요구사항
| ID | 페이지 | 요구사항 |
|----|--------|----------|
| P1 | 홈 | 히어로 배너 1개, 카테고리 바로가기, 신상 8개, 베스트 8개, 간단한 푸터 |
| P2 | 상품 목록 | 카테고리 탭, 정렬(신상/낮은가격/높은가격), 사이즈·컬러 필터, 하트 버튼 |
| P3 | 상품 상세 | 이미지 2장 + 썸네일, 사이즈·컬러 필수 선택, 옵션별 품절 표시, 수량, 담기, 하트 |
| P4 | 장바구니 | 수량 변경(1~10), 삭제, 상품 금액 합계, 빈 상태. 주문 버튼 없음 |
| P5 | 위시리스트 | 찜한 상품 목록, 해제, 빈 상태 |

### 장바구니 규칙
- 같은 상품·사이즈·컬러를 다시 담으면 수량 합산 (최대 10)
- 합계는 상품 금액 합만 표시 (배송비·쿠폰 없음)

## 5. 데이터
- 상품: id, 이름, 카테고리, 정가, 할인가(선택), 컬러[], 사이즈[], 품절 옵션(컬러|사이즈), 신상/베스트 플래그, 설명
- 이미지: 상품 컬러를 반영한 자체 제작 SVG 일러스트(외부 이미지 의존 없음), 상품당 2장

## 6. 완료 기준
1. 탐색 → 상세 → 담기 → 장바구니 합계 흐름이 모바일/데스크톱에서 동작한다.
2. 새로고침 후에도 장바구니·위시리스트가 유지된다.
3. `npm run build`가 성공하고 Vercel에 배포 가능한 상태다.

## 7. 검증 방법
- `npm run build` 성공
- 브라우저에서 수동 확인: 필터 조합, 품절 옵션 비활성, 수량 상한, 빈 상태 화면, 새로고침 유지

## 8. 결제 연동 (v1.1)
| 항목 | 결정 |
|------|------|
| PG | 토스페이먼츠 결제위젯(SDK v2, `widgets.requestPayment`), **테스트 모드**, 비회원 결제 |
| 키 | 기본값: 토스 공식 문서의 공개 결제위젯 테스트 키. 본인 키는 `VITE_TOSS_CLIENT_KEY`(결제위젯 연동 키)로 교체 |
| 흐름 | 장바구니 → 주문서(받는 사람/휴대폰/주소 + 결제위젯) → 결제 → 성공/실패 화면 |
| 금액 | 상품 금액 합계 (배송비·쿠폰 없음) |
| 승인(confirm) | **생략** — 서버가 없으므로 결제 인증까지만 진행. 결제가 최종 승인되지 않음 |
| 성공 화면 | 주문번호·금액이 저장된 주문과 일치할 때만 표시, 이후 장바구니 비움 |

### 알려진 한계
- 승인 API를 호출하지 않아 토스 측 결제는 최종 완료되지 않는다. 실제 결제로 쓰려면 서버(예: Vercel 함수)에서 시크릿 키로 승인 API를 호출해야 한다.
- 금액은 클라이언트에서 계산되므로 위변조 검증이 없다(승인 단계 도입 시 서버에서 재검증 필요).
- 주문 내역 조회, 취소/환불은 범위에 없다.
